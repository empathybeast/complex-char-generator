Персона — генератор карточек персонажей

КАК ОТКРЫТЬ
Открой index.html в браузере (двойной клик или перетащи в Chrome / Firefox / Safari).
Интернет нужен только для шрифтов Google. Генератор, история и JPG работают локально.

ЧТО ВНУТРИ
- index.html — готовый сайт, один файл
- исходники/ — React-версия того же генератора (для разработчиков)

ИСТОРИЯ хранится в браузере (последние 50 карточек).
